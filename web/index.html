      端侧产品观测能力

      时间线分段与语义边界

      资产三态推导判据

      目录存在文件不等于已启用：installation_state 由准入事务推导，runtime_state 由执行记录推导，activation_state 仅在产品会话确认加载（product_loaded=true）时记为 enabled；不可探测时记 unknown，拒收客户端自报状态。

      Ed25519 验签与去重规则

      同名同类型同产品的逻辑资产只登记一次；副本按（资产，主机，产品作用域）去重。signature_verified 仅能由服务端使用发布方公钥对 content_hash 计算写入，请求体自带布尔值一律 400 拒收。

      台账关联键说明

      扫描失败语义

      超时、解析错误与部分覆盖均显式保持失败状态，绝不伪装成“无发现项”。原始报告正文仅在具备 read_raw_report 权限时单独复核。

      丢失率与采集静默

      端侧因队列封顶、重试耗尽或审计轮转缺口丢数时均会登记。丢失率 = 丢失记录 / 尝试送达记录；轮转缺口独立展示不并入分母；有执行而长期无对账上报标记为采集器静默。

      模型密钥隔离

      供应商列表仅展示接口地址与密钥是否已配，绝不读取或回显密钥明文；密钥仅由进程环境变量注入并消费于内存。

      调用审批门控

      ASGP 审批绑定设备、调用 ID 与参数 SHA-256 哈希，不等于产品原生弹窗；页面不回显原始命令参数；拒绝、超时或控制面不可达均默认不放行。

      策略分层与执行证明

      固有、运行、暴露面三维度分立评估，按当前活跃策略版本顺序求值；无活跃版本返回 500 而不静默回退；版本激活为单事务原子替换，停用版本不可复用。策略决定记录 enforcement_expected=false，真实阻断须另有执行证据。

      受管安装与 Incident 闭环

      受管安装仅在托管目录（inbound / staging / installed / backup）内执行真实文件状态转移，拒绝越界路径、符号链接及 setuid/setgid 文件。Incident 关闭必须关联开启后的同目标干净复测 DetectorRun，不认客户端自报 retest_passed。
