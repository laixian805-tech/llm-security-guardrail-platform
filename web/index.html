      准入

      准入安装

      受管安装器只在平台托管目录（inbound / staging / installed / backup）内做真实的 stage/commit/verify/reconcile/rollback，每次转移都有文件系统后果，body 布尔值不能代替安装证据。托管目录是平台自己的包管理存储，不代表 Agent 产品已加载该包。
