# ASGP 调用审批与运行时证据边界

状态：已采纳。

Codex 0.166.0 实测忽略 Hook ask。为满足用户要求的确认流程，ASGP 在明确启用的需确认规则上使用控制面审批：请求绑定设备、产品版本、会话、调用和完整参数哈希；批准后 Hook 输出 allow，拒绝、超时或不可达输出 deny。只在这条路径同步等待，其余 observe 继续本地持久入队；产品原生 confirm 能力保持真实声明。代价是审批期间依赖控制面可达，产品 Hook 超时必须长于审批截止时间；不引入伪造 ask 回执或自动批准。

Linux Audit 只采集测试 UID 与指定规则的进程/文件/网络事实，不保存命令参数和 PROCTITLE。Hook 上下文锚点用于建立调用到进程的候选边；PID 谱系受时间约束，并发候选冲突时全部保留，不用时间接近强行唯一归因。策略、审批、准入状态和实际生效证据继续分开；没有安装器的 stage/commit/verify 请求明确失败，不能由客户端布尔值声称安装已成功。
