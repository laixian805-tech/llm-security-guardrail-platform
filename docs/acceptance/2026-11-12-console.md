# 控制台五中心工作台实测记录（2026-11-12）

本轮把治理工作台从「治理记录」占位页扩成资产、检测、运行、策略、准入、Incident 六个可操作视图，并用真实 headless Chromium 走完整流程。受控端仍为 116.62.28.177，开发机不装 Hook；本节所有结论来自开发机上的真实浏览器会话。

## 验证方式

- 起真实 HTTP 服务（临时库 + 临时托管目录），导入一份带 3 条发现项的报告、在托管 inbound 放一个真实包、创建一条准入检查。
- headless Chromium 通过 CDP 驱动：登录、逐中心渲染、点击准入每个转移、创建并流转 Incident、创建风险评估并求值、创建并激活策略版本，再用只读账号复核权限。
- 判定标准：按钮点击后服务端状态真的变化、托管目录里文件真的落盘/移除、只读账号所有写操作置灰。界面文案不计入证据。

## 结果

40 项检查全部通过，浏览器控制台无未捕获异常（仅登出后探测会话产生的 401，属预期）。

| 面 | 实测结果 |
| --- | --- |
| 资产中心 | 产品能力矩阵按版本展示：事件观测聚合等级、每类 Hook 的能力与是否执行前、ASGP 调用审批是否可用、可摄入性；主机与执行上下文按主机聚合。未实测事件只显示 observe |
| 检测中心 | 扫描运行与发现项照常渲染；发现项可作为风险评估证据勾选 |
